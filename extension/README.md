# LeadsBuddy.ai Chrome Extension

Chrome extension for finding and enriching B2B leads directly from the browser. Built with **Manifest V3**, **React 18**, **TypeScript**, and **Vite**.

---

## Folder Structure

```
extension/
├── public/
│   ├── manifest.json       # MV3 manifest (copied to dist/ by Vite)
│   └── icons/              # PNG icons (auto-generated by npm prepare)
│
├── src/
│   ├── background/         # Service worker (MV3 background)
│   ├── sidepanel/          # Side panel UI (React app)
│   ├── content/            # Content scripts
│   ├── components/         # Shared React components
│   ├── hooks/              # Shared React hooks
│   ├── services/           # API service modules
│   ├── utils/              # Utility functions
│   ├── types/              # TypeScript types & interfaces
│   └── constants/          # App-wide constants
│
├── scripts/
│   └── generate-icons.js   # Generates placeholder PNG icons (no deps)
│
├── vite.config.ts
├── tsconfig.json
└── package.json
```

---

## Development Setup

### 1. Install dependencies

```bash
cd extension
npm install
```

> `npm install` runs the `prepare` script automatically, which generates placeholder PNG icons in `public/icons/`.

### 2. Build the extension

```bash
npm run build
```

This outputs the compiled extension to `extension/dist/`.

### 3. Watch mode (auto-rebuild on save)

```bash
npm run dev
```

---

## Install in Chrome (Developer Mode)

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (toggle in the top-right corner)
3. Click **Load unpacked**
4. Select the `extension/dist/` folder
5. The LeadsBuddy.ai extension will appear in your toolbar
6. Click the extension icon — the **side panel** opens on the right

After any code change, run `npm run build` (or keep `npm run dev` running) and click the **reload** button on the extension card in `chrome://extensions/`.

## Not Yet Implemented

The following features are intentionally omitted from this base setup:

- Authentication / login
- Backend API calls
- CoreSignal / PDL integration
- LinkedIn / Sales Navigator detection
- Lead search & unlock
- Credit system
- State management
- Settings
- Notifications
- Background jobs / RabbitMQ
- Storage (chrome.storage)

## Architecture Notes

| File | Role |
|------|------|
| `src/background/index.ts` | Service worker — opens side panel on action click |
| `src/sidepanel/App.tsx` | Side panel React root — placeholder UI |
| `src/content/index.ts` | Content script — placeholder, no DOM interaction |
| `public/manifest.json` | MV3 manifest — permissions, entry points |

The Vite build produces three entry bundles:

- `dist/background/index.js` — service worker
- `dist/content/index.js` — content script
- `dist/sidepanel/index.html` + associated JS — side panel
